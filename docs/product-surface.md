# Product Surface: @apet97/clockify-addon-sdk

This package provides a server runtime SDK for CAKE.com marketplace add-ons targeting Clockify.

## Scope

### Inclusions
- Support for manifest schemas 1.2, 1.3, 1.4, and 1.5.
- Autogenerated builders matching schema definitions.
- Core server routing (GET `/manifest`, path validators, 405 Method Not Allowed, 500 Error Handler).
- Clockify Addon lifecycle, component, settings, and webhook registrations.
- RS256 JWT signature verification (`jose`).
- Adapters for Node.js `http`, Express, and Fetch API.

### Exclusions
- Calling the Clockify REST API. The SDK verifies incoming requests and extracts environment claims;
  it does not call Clockify APIs on your behalf.
- Pumble and Plaky add-on implementations.
